# Acoustic Emotion Vocal Signature — Machine Learning Project

Project for the **Machine Learning / Apprendimento Automatico** module (A.Y. 2025/2026).

**Classification** problem: predict a speaker's emotional state (`Mood`) from acoustic voice
features (pitch, jitter, shimmer, speech rate, MFCCs, etc.).

For each algorithm, the validation produced with **scikit-learn** is compared against an
**equivalent** validation run in **WEKA** (point 4 of the assignment).

## Setup

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Launch Jupyter and run the notebook:

```bash
jupyter notebook notebooks/AcousticEmotionVocalSignature.ipynb
```

Running all cells in order:

1. trains and validates 5 scikit-learn classifiers
   (Logistic Regression, Naïve Bayes, KNN, Decision Tree, MLP) on a stratified 80/20 holdout;
2. the `class_scores` table reports **Accuracy**, **F1 (weighted)**, **ROC AUC (weighted)**;
3. the final cells regenerate `weka-files/dataset_esame.arff` for the WEKA comparison.

## WEKA comparison

Goal: reproduce in WEKA the **same** validation used in the notebook
(80/20 holdout + standardized features) and compare the metrics.

### Install WEKA

Download from <https://www.cs.waikato.ac.nz/ml/weka/> (requires Java).

### Run the 5 classifiers (recommended: CLI script)

Reproducible, no clicking. From the repo root:

```bash
# auto-detects weka.jar in common locations
weka-files/run_weka.sh

# or pass the path explicitly
WEKA_JAR=/Applications/weka-3-8-6/weka.jar weka-files/run_weka.sh
```

The script runs each classifier through `FilteredClassifier` with **Standardize** on an
80/20 holdout (seed 1), saves the full output to `weka-files/out/<name>.txt`, and prints the
relevant lines. Algorithm mapping (same 5 models as the notebook):

| Notebook (scikit-learn)   | WEKA classifier                                |
|---------------------------|------------------------------------------------|
| LogisticRegression        | `functions.Logistic`                           |
| NaïveBayes (Gaussian)     | `bayes.NaiveBayes`                             |
| KNN                       | `lazy.IBk -K 5`                                |
| DecisionTree (CART)       | `trees.J48` (C4.5 ≈ CART, similar algorithm)   |
| MLP                       | `functions.MultilayerPerceptron`               |

> Note: `J48` (C4.5) is not identical to scikit-learn's CART — it is the standard WEKA
> substitute, so small differences on the Decision Tree are expected.

### Alternatives (GUI)

- **Explorer** — *Classify* tab. Choose `meta → FilteredClassifier`, set
  `filter = unsupervised.attribute.Standardize` and `classifier =` one of the above,
  *Test options → Percentage split = 80%*, class `Mood`. Press *Start* once per classifier
  (5 manual runs). Resulting config string:
  ```
  FilteredClassifier -F "weka.filters.unsupervised.attribute.Standardize" -W weka.classifiers.trees.J48 -- -C 0.25 -M 2
  ```
- **Experimenter** — batch all 5 classifiers in one run and get a comparison table.

> ⚠️ Filter choice: use **`unsupervised.attribute.Standardize`**, **not**
> `supervised.attribute.Discretize`. `Standardize` is the z-score `(x − mean) / std` and only
> uses the features (ignores the class → *unsupervised*), exactly like `StandardScaler`.
> `Discretize` bins numeric features and does **not** match `StandardScaler` → non-comparable results.
>
> Why `FilteredClassifier` and not filtering in *Preprocess*: it fits the filter on the
> training split only (no data leakage), like scikit-learn's `Pipeline`.

> The 10 classes are balanced (~10% each), so **no** resampling is needed in WEKA.

### Read the metrics

From each classifier's output:

| Notebook metric  | WEKA output                                |
|------------------|--------------------------------------------|
| `Test_Accuracy`  | *Correctly Classified Instances* (%) ÷ 100 |
| `F1_Score`       | *Weighted Avg. F-Measure*                  |
| `ROC_AUC`        | *Weighted Avg. ROC Area*                   |

### Fill the comparison in the notebook

In the **"scikit-learn vs WEKA comparison"** cell, fill the `weka_results` dictionary with the
values read above (0–1 scale):

```python
weka_results = {

    'NaiveBayes':         [0.xx, 0.xx, 0.xx],

    'DecisionTree':       [0.xx, 0.xx, 0.xx],
    'MLP':                [0.xx, 0.xx, 0.xx],
}
```

Re-running that cell and the next one produces the comparison **table** and **bar charts**
(scikit-learn vs WEKA) for each metric.

| Value | Emotion   | Value | Emotion    |
|:-----:|-----------|:-----:|------------|
| 0     | Angry     | 5     | Fearful    |
| 1     | Bored     | 6     | Happy      |
| 2     | Calm      | 7     | Neutral    |
| 3     | Confused  | 8     | Sad        |
| 4     | Excited   | 9     | Surprised  |
